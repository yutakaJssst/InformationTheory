2026年9月5日の比較版原稿に対応。

公開・共有してよい情報だけを記入します。

- 解決したい課題：

- AIが役立った点：

## 3分発表の配分例

| スライド | 内容 | 時間目安 |
|---|---|---|
| 1 | タイトル、自己紹介 | 10秒 |
| 2 | 研究テーマの紹介 | 20秒 |
| 3 | 研究で分かったことと根拠となる成果物 | 1分 |
| 4 | AIを使った作業、検証方法、効果と限界 | 1分 |
| 5 | まとめ、今後の展望 | 30秒 |

発表3分、質疑応答2分を目安にします。
声に出して時間を測り、超える場合は伝える内容を絞ってください。
AIに原稿の圧縮を依頼したときも、研究の成果と根拠、検証方法が落ちていないかを自分で確かめます。

## ピアレビューの記入欄

発表テーマ：

| 観点 | 確認すること | コメント |
|---|---|---|
| 研究内容 | 背景、目的、方法、結果が分かるか | |
| 新規性 | 既存研究との差分が説明されているか | |
| AI活用 | 使った場面と検証方法が具体的か | |
| 倫理と公開範囲 | 機密情報や個人情報への配慮があるか | |
| 発表資料 | 1枚1メッセージで、話とスライドが対応しているか | |
| 今後の方針 | AIに任せる部分と自分で判断する部分が明確か | |

必要に応じて各観点を5点満点で採点してもよいですが、点数だけで終わらずコメントを添えてください。

- 良かった点を1つ：
- 改善点を1つ（場所、理由、直し方）：

記入例：「3枚目のグラフは、縦軸の単位が口頭でしか説明されなかったので、軸ラベルに単位を書くと初見でも分かると思います。」
