COPY & CUSTOMIZE

コピーして使うプロンプト

書籍で考え方と代表例を確認した後、角括弧の部分を自分の課題に合わせて書き換えてください。Role（役割）は必要な場合だけ残します。

文献調査：サーベイの起点を見つける 
【R】あなたは［分野名］の研究者で、文献調査の専門家です。

【O】以下のテーマに関するサーベイ論文・レビュー論文を探すための検索戦略を提案してください。

【C】テーマ：［テーマ］
知りたいこと：［具体的な問い］
すでに知っていること：［既知の情報］

【F】推奨する英語検索語を5セット、推奨データベース、注意すべき関連分野を示してください。論文名を挙げる場合は、未確認情報と確認済み情報を区別してください。
英語論文：Abstractを改善する 
【R】あなたは［分野名］の学術英語ライティングに詳しい校正者です。

【O】以下の日本語要旨を、学術英語のAbstractとして書き直してください。

【C】日本語要旨：［ここに貼る］
投稿先：［学会・ジャーナル名］
語数制限：［語数］語以内

【F】背景、目的、方法、結果、意義の順に構成してください。事実や数値を追加せず、不足している情報は不足していると明記してください。主な修正理由も示してください。
コード：エラーの原因を調べる 
【R】あなたはPythonのデバッグに詳しく、初学者への説明が得意な支援者です。

【O】次のエラーの原因を切り分け、最小限の修正を提案してください。

【C】実行したいこと：［目的］
コード：［コード］
エラーメッセージ：［全文］
実行環境：［例：Google Colab / Python 3.x］

【F】1. 原因の説明 2. 確認手順 3. 修正後のコード 4. 再発防止の順で、専門用語を説明しながら回答してください。
データ分析：分析計画を立てる 
【R】あなたは再現性を重視するデータ分析者です。

【O】以下の研究目的とデータに対する分析計画を提案してください。

【C】研究目的：［目的］
データ概要：［種類、件数、変数］
仮説：［検証したい仮説］

【F】推奨手法と理由、前処理、検証方法、可視化、結果を解釈するときの注意点を順に示してください。前処理は、訓練データと評価データの分割後に行う前提で計画してください。追加で確認すべき情報は、分析を始める前に質問してください。
スライド：発表構成を作る 
【R】あなたは学会発表のプレゼンテーションコーチです。

【O】以下の研究内容を、［発表時間］分の発表スライド構成案にしてください。

【C】研究タイトル：［タイトル］
聴衆：［想定聴衆］
研究概要：［3〜5文］
最も伝えたいこと：［1文］

【F】各スライドについて、タイトル、1文メッセージ、必要な図表、推定時間を表で示してください。与えていない結果は作らないでください。
経験の言語化：STAR法で整理する 
【R】あなたは大学院生の経験を具体化するキャリアコーチです。

【O】以下の経験メモをSTAR法で整理してください。

【C】経験メモ：［箇条書き］
伝えたい強み：［強み］
提出先・読み手：［企業、奨学金審査など］

【F】S（状況）、T（課題）、A（行動）、R（結果）を分け、情報が不足している箇所は推測で埋めず質問として列挙してください。誇張や架空の数値は追加しないでください。

入力前の確認： 未公開の研究データ、個人情報、共同研究先の秘密情報、APIキーなどを、そのまま外部AIサービスへ入力しないでください。

Pythonを初めて使う方へ

  1. 各章の「手順」を先に読み、同じ章のファイルを一つのフォルダーへ保存します。
  2. パソコンに環境を作りたくない場合は、Google Colabなどのブラウザ上の実行環境を利用できます。
